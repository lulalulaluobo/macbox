# MacNAS 今日开发总结

日期：2026-09-12

## 一、发布与启动方式

- 明确采用“预编译二进制压缩包 + `install.sh` + 可选 `MacNASMenu.app`”的发行方式。
- 不再依赖 DMG；Web 控制台是主界面，菜单栏助手只负责启动、停止、状态查看、日志和卸载入口。
- 支持 Apple Silicon 与 Intel macOS 架构发行包。
- `install.sh` 会安装到用户级目录，不依赖开发机路径；最终用户不需要 Node.js。
- 支持命令行启动局域网 Web 服务：

  ```bash
  macnas --host 0.0.0.0 --port 19808
  ```

- 菜单栏助手启动后端时会传入局域网监听地址，并支持打开 Web 控制台。
- 完整卸载区分“仅卸载程序”和“删除 MacNAS 实例、镜像、配置及数据”。不会误删其他 Lima 实例或宿主机无关 Docker 数据。

## 二、首次启动状态机与诊断中心

- 初始化流程拆分为：环境检查、虚拟机配置、启动服务三个阶段。
- 增加 Lima、虚拟机、数据盘、SSH、Docker、本机目录直通等检查项。
- 启动和安装任务使用后台任务状态机，页面刷新后可以恢复正在执行的任务状态。
- 启动失败会保留任务阶段、进度和具体错误，并可进入诊断中心查看阻断原因。
- 修复菜单栏 App 场景下 Homebrew 路径未继承的问题：现在会主动识别 `/opt/homebrew/bin/limactl`、`/usr/local/bin/limactl` 等路径。
- 对临时检测失败进行区分，避免把短暂 API 错误误判成“未安装”或清空已有状态。

## 三、存储、扩展盘与本机目录直通

- 增加存储挂载契约和探针验证，初始化与诊断阶段会检查数据盘是否真实可访问。
- 改进外置盘、256GB 本机盘和 2TB 主存储盘的状态展示。
- 本机目录直通支持候选目录扫描和分类选择，配置会映射到 Lima 虚拟机内的固定目录。
- 直通配置与运行 MacNAS 的 Mac 绑定，避免把手机或其他访问设备的路径误认为服务器本机路径。
- 增加直通健康探针，能识别“配置存在但 VM 内实际不可见”的情况。
- 处理历史数据由 root 创建、普通管理用户无法读取的问题：文件读取和安全文件操作通过 VM 内的受控提权命令执行，同时仍限制在 `/data` 范围内。

## 四、Docker 与应用导航

- Docker Compose 部署会读取宿主机 `ports` 映射，并加入 Lima 端口转发白名单，使新 Docker 服务默认可通过局域网访问。
- Docker 容器操作保留运行、停止、重启、日志和删除能力。
- 首页 Docker 服务导航与真实容器列表同步：
  - 容器删除后立即移除对应首页导航；
  - 外部删除容器后，下一次轮询或刷新会自动清理残留导航；
  - Docker API 临时失败时不会误删用户导航配置。
- Docker 容器可以添加到首页服务导航，自动读取服务名称和内网访问地址，并支持预设图标。
- 应用商城中的下载工具模板补充了容器所需的权限配置，包括 `SYS_ADMIN` 和 `apparmor=unconfined`。

## 五、Web 终端与 AI CLI

- Web 终端支持 Codex、Claude、Anti Gravity 三个 CLI 快捷入口。
- Docker 容器管理页可以把容器最近日志填入 Web 终端输入框，用户确认后再交给 AI CLI 分析维护。
- 终端任务状态持久化，刷新页面后仍能看到任务记录；服务重启时未完成任务会标记为中断，不会伪装成成功。
- 增加终端默认登录身份设置，支持普通用户和 root 身份选择。
- 增加 AI CLI Skill 目录设置：
  - 扫描 Mac 本机的 `.agents/skills`、`.codex/skills`、`.claude/skills` 等候选目录；
  - 以只读方式映射到 VM 的 `/home/macnasctl/.agents/skills` 和 `/root/.agents/skills`；
  - 保存映射后提示重启 VM，使 AI CLI 可以读取 Skill。

## 六、文件管理体验

- 文件管理上方保留 NAS 根目录、Docker 目录和用户收藏目录，减少常用路径跳转成本。
- 文件夹增加收藏/取消收藏功能；收藏状态使用黄色星星图标表示，文字保持高对比度。
- 文件操作面板增加：复制、移动、重命名、删除、路径复制、压缩和下载。
- 单文件下载修复 0KB 问题：
  - 根因是历史文件权限为 `root:root` 且权限较严格，后端读取命令失败后浏览器仍创建了空文件；
  - 下载前先验证文件信息，并在真正读到数据后再返回成功响应；
  - 文件大小和 `Content-Length` 与源文件保持一致。
- 文件夹支持自动生成 ZIP 后下载，移动端也不再依赖新窗口弹出。
- 增加任务列表入口，传送任务不再长期占用文件页面；可以查看状态、进度、速度和当前文件，并支持清理历史记录。

## 七、压缩与解压

- 文件和文件夹均可创建压缩包。
- `.zip`、`.rar`、`.7z` 文件显示解压入口。
- ZIP 创建和解压使用虚拟机内 Python 标准库实现，不需要额外安装工具。
- ZIP 解压增加路径安全校验，阻止绝对路径、`..` 路径和恶意符号链接逃逸。
- 7z/RAR 调用 VM 内的 `7z`、`7zz`、`unrar` 或 `rar` 工具；当前测试 VM 未预装这些工具，界面会给出明确安装提示。
- RAR 创建依赖官方 `rar` 工具，7z 创建依赖 `7z/7zz`；ZIP 是当前开箱即用格式。

## 八、夸克云盘

- 文件管理支持挂载远程云盘，第一阶段接入夸克云盘。
- 支持网页扫码鉴权，不要求用户在 MacNAS 中粘贴 Cookie、手机号密码或短信验证码。
- 挂载成功后，夸克云盘作为文件页中的独立磁盘入口显示。
- 已实现云端目录浏览、新建文件夹、重命名、删除和文件/文件夹下载到 NAS 本地目录。
- 云端下载使用后台任务，记录文件数量、总大小、已完成字节数、速度、当前文件和错误状态。
- 下载失败会保留错误原因，刷新页面后仍可查看任务记录。
- 云盘挂载、鉴权和任务配置使用受限权限保存。

## 十、当前已知限制

- 当前 VM 没有预装 `7z/7zz/unrar/rar`，所以非 ZIP 格式需要先在 VM 内安装对应工具。
- 夸克云盘当前采用扫码鉴权，手机号登录仍由夸克官方页面负责；MacNAS 暂不接管短信验证。
- 直通目录必须选择运行 MacNAS 服务的 Mac 本机目录，手机浏览器选择的目录不会映射到服务器。
- 菜单栏 App 为未签名开源程序，首次运行可能需要在 Finder 中右键选择“打开”。

## 十一、推荐的后续优先级

1. 为 7z/RAR 增加可选的一键安装工具流程，并在诊断中心显示工具缺失状态。
2. 增加云盘任务暂停、取消、重试和并发数设置。
3. 将 Docker 导航、收藏目录和云盘挂载配置逐步迁移到服务端账户配置，支持多浏览器和多用户一致同步。
4. 为发行包增加签名和自动更新，降低 macOS 首次运行的安全提示成本。
