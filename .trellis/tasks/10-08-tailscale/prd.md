# Tailscale 远程访问

用户已确认可行性评估并要求增加模块。采用官方 Linux 客户端，在设置页提供远程访问。默认仅供获准加入用户网络的设备使用，公开网址留待独立需求。

范围：按需安装官方客户端、打开官方设备授权页、等待批准/连接状态、设备名称及地址、应用入口、后台访问、暂停/恢复、退出账号。升级和重启保留设备状态；不收集账号密码，不要求用户复制 Auth Key，不开启家庭网段路由或出口节点，不改用户网络策略。

实现复用官方 CLI、本地守护进程接口、现有运行系统执行和后台任务结构。本地接口仅通过 Linux 内的 Unix 套接字访问，恢复操作仅修改连接开关，保留已有网络偏好。管理员控制连接，读取授权链接仅限管理员；链接和设备密钥不写入普通任务记录、日志、配置导出或发行包。客户端放在 Linux 系统中，避免修改 Mac 上已有 Tailscale。后台仍需 MacBox 自身登录。

验收：安装/登录/待批准/在线/过期/暂停状态可解释，地址与应用入口可复制和打开；后台入口保留原有登录、Host/Origin 和 WebSocket 规则；状态在系统重启后保留；重复点击不启动并行安装/登录；退出与暂停行为不同；Go 与前端检查及本机安装通过，真实账号授权交由用户完成。首版使用私有 IP 入口，设备之间通过 Tailscale 加密连接；域名证书和公开访问另行设计。

先本机部署供用户测试，是否继续发布新版按后续测试结果处理。

2026-10-09：用户已明确授权推送远程 Git 并更新 Release，发布版本为 v0.1.4。发布前只读确认设备已在线、私有地址已分配、后台中转处于运行状态，通过私有地址访问后台返回 HTTP 200。发行包覆盖 Apple 芯片与 Intel 的 DMG、命令行压缩包及 SHA-256，保留 v0.1.3。
